# 失效模式索引

本目录记录已经观察、定位或修复过的可复用失效模式。代码问题修复或测试前，应先查看本索引，避免重复引入历史问题。

## 记录规则

- 每个失效模式一个独立 Markdown 文件。
- 文件名使用时间戳加简短 slug，例如 `20260718-startup-readiness.md`。
- 新增、重命名或删除文件时，必须更新本索引。
- 每个文件必须包含：失效场景、定位方式、根因、最终修复、验证方式。
