# 文档更新规则

## 状态

当前有效。

## 规则

- 代码变更影响架构、运行时、契约、验证流程或 LLM 工作流时，评估是否更新 `docs/`。
- 新增 docs 文件时，必须放入正确目录并同步 README 或 index。
- 研究过程、论文、候选材料和开源仓库对比不得写入主仓 `docs/`。
- 非研究阶段记录默认放入 `guides/`。
- 常读入口保持短，不放长推演或历史过程。
- 不确定或未来计划标记为 `状态：暂定`。
- 新增或修订 PRD 前必须读取 `docs/00-overview/roles-and-use-cases.md`，对顾客、客服、知识运营、后台管理员、微信平台管理员做全面角色影响推演；不能只从单一角色视角定义需求。

## 行动前

涉及复杂文档体系变更时，先使用 `reasoning-map` 推演影响面。

## 行动后

复核索引同步、token 控制、根规则与局部规则一致性。
