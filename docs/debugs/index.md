# 调试记录索引

本目录记录复杂问题定位过程。它保留定位路径、临时日志标签、关键状态信号和最终状态，方便后续复用。

## 记录规则

- 每个重要调试过程一个独立 Markdown 文件。
- 文件名使用时间戳加简短 slug，例如 `20260718-startup-debug.md`。
- 新增、重命名或删除文件时，必须更新本索引。
- 调试记录应包含：问题、定位方法、修复记录、最终状态、关联记录。
